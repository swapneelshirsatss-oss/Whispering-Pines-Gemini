## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Approval & Workflow Rules

- **User Confirmation Required**: Do not execute or apply file changes to content, pages, or layout logic until the user explicitly reviews and confirms the proposed approach.

## Technical SEO & Duplicate Content Guardrails

- **No Duplicate Content Across Routes**: Never replicate identical full-length article or landing page content on multiple separate URLs (e.g., `/resort-near-mukteshwar/` vs `/blog/resort-near-mukteshwar/`). Duplicate content harms SEO indexing and rankings. Differentiate content, consolidate under a single canonical URL, or set explicit canonical tags.
